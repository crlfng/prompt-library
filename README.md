# Prompt Library

A systematically organized collection of tested prompts and prompt engineering techniques for working with Large Language Models (Claude, ChatGPT, and others).

## Philosophy

Effective prompting is a learnable skill. This library documents prompts that work, why they work, and the patterns behind them. Each prompt has been tested and refined through iteration.

## Structure

- **writing/** — Prompts for content creation, editing, and revision

- **analysis/** — Prompts for data analysis, research, and synthesis

- **evaluation/** — Prompts for comparing, rating, and critiquing outputs

- **coding/** — Prompts for code generation, debugging, and explanation

- **meta-prompts/** — Prompts about prompting itself (recursive and meta-level)

## How to use this library

1. Pick a category based on your task

2. Find a prompt that matches your need

3. Adapt the prompt to your specific context

4. Note what works and what doesn't — contribute back
