# Prompt Improvement Framework

**Purpose:** Analyze and refine prompts that aren't working well

**The Prompt:**
My prompt isn't working well. Help me improve it:
Original prompt:
[PASTE YOUR PROMPT]
What's wrong:
[DESCRIBE THE PROBLEM — e.g., "responses are too vague", "ignores constraints"]
Context:
[WHAT RESULT DO YOU ACTUALLY WANT]
Please:

Identify what's unclear in the original prompt
Suggest 3 specific improvements
Write a revised version that fixes these issues
Explain why the revised version works better

Make it concrete, not abstract.

**Example Input:**
Original prompt: "Write me a good email"
Problem: Responses are too formal and generic
Want: Professional but friendly, addresses specific client issue

**Example Output:**
Issues in original:

No context about situation
"Good" is vague (what makes an email good?)
No tone guidance
No length constraint

Improvement 1: Add specific context
Improvement 2: Define tone explicitly
Improvement 3: Specify output format
Revised prompt: [Complete prompt with all fixes]

**Why it works:**
- Teaches meta-thinking about prompting
- Shows how to debug failed prompts
- Critical skill for AI work
