# Content Outline Generator

**Purpose:** Quickly structure long-form content (articles, reports, guides) with clear hierarchy and key points

**The Prompt:**
You are a content strategist. Create a detailed outline for this content:
Topic: [WHAT YOU'RE WRITING ABOUT]
Length: [BRIEF 500 WORDS / MEDIUM 1500-2000 / LONG 3000+ WORDS]
Audience: [WHO WILL READ THIS]
Goal: [WHAT SHOULD READERS LEARN/DO]
Create an outline with:

Clear main sections (H2)
Subsections (H3) under each
2-3 key points per subsection
Suggested examples or data to include

Make it logical and easy to follow.

**Example Input:**
Topic: Getting started with prompt engineering
Length: Medium 1500-2000 words
Audience: Beginners with no ML background
Goal: Understand core concepts and write their first effective prompt

**Example Output:**
Getting Started with Prompt Engineering
1. What is Prompt Engineering?

Definition and why it matters
How LLMs process text
Real-world use cases

2. Core Principles

Be clear and specific
Provide context
Specify output format

[... more sections ...]

**Why it works:**
- Prevents blank page syndrome
- Forces logical structure before writing
- Provides a roadmap to follow
